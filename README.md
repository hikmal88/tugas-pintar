# Tugas Pintar

Aplikasi to-do list ringkas menggunakan Next.js.

## Ciri-ciri
- Tambah tugasan dengan Enter atau butang Tambah
- Tanda tugasan selesai/belum selesai
- Penapis Semua, Belum selesai, dan Selesai
- Padam tugasan atau semua tugasan yang selesai
- Reka bentuk responsif

## Jalankan

```bash
npm install
npm run dev
```
